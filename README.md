# O-jarvis

Assistant personnel desktop pour Ubuntu. On lui parle à voix haute (« Hey Jarvis »), il se souvient, agit sous contrôle et sait s'étendre.

- App : Tauri v2 + React + TypeScript.
- Cerveau : moteur Python (FastAPI) lancé par l'app, sur `127.0.0.1` uniquement.
- Données : SQLite local (relationnel, vecteurs, graphe).

Le projet est en construction. L'état du travail est dans [`PROGRESS.md`](./PROGRESS.md), les choix dans [`DECISIONS.md`](./DECISIONS.md), le journal dans [`docs/journal/`](./docs/journal/README.md).
